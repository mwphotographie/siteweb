# Portfolio photographe

Portfolio réalisé avec Next.js.

## Installation locale

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000

## Personnalisation

Modifier `app/page.js` pour :
- le nom du photographe
- l'email
- le lien Instagram
- les textes
- les photos

Les photos de démonstration utilisent Unsplash. Pour un vrai portfolio, remplace-les par tes propres images.

## Déploiement

Le projet peut être connecté directement à Vercel depuis GitHub.
